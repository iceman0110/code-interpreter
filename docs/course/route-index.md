# Express route registration index

[Course home](README.md) · [Curated API reference](api-reference.md)

Generated by parsing literal route registrations in TypeScript. **Paths are local to each router before mounting.** Middleware ordering, conditions, authentication, feature gates, and router mounting determine the actual availability. A registration can be logging middleware rather than the final handler; duplicate registrations across alternative entrypoints are not extra services. This index excludes custom Bun routing (notably the tool call server), computed route paths, and `.use()` mounts. Read the curated API reference for full paths and visibility.
